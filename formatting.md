# Formatting
{: .no_toc }

Everything in the visual's **Format** pane. Settings that have no effect in the chosen layout or
perspective are hidden, so you only see what applies.
{: .fs-6 .fw-300 }

## Layout

| Setting | What it does | Applies to |
|:--------|:-------------|:-----------|
| Visual perspective | **Risk Bowtie** or **Barrier View** (Premium) | — |
| Barrier layout | Grouped · Vertical · Auto layout · Auto layout, grouped barriers — see [the four layouts](using-the-visual#the-four-layouts) | Risk Bowtie |
| Start expanded | Open barrier groups expanded instead of collapsed | Risk Bowtie |
| Show zoom controls | The + / – / ⤢ buttons | Every layout (Premium) |
| Animate degraded edges | Animates connectors after a failed or degraded barrier | Auto layouts, Barrier View |
| Show expand/collapse toolbar | The Expand All / Collapse All buttons | Risk Bowtie (Premium) |
| Toolbar position, button background / text / border | Where the toolbar sits and how it looks | When the toolbar is shown |

## Colours
{: .d-inline-block }

Premium
{: .label .label-purple }

Risk, cause, consequence, barrier fill and border, connectors, detail-panel background / text /
border, and the risk score default colour. Text on every card switches between white and dark to
stay readable against the colour you pick.

In the free view the colours are fixed, except the risk score default colour. In high-contrast
mode every layout uses the system colours.

## Text
{: .d-inline-block }

Premium
{: .label .label-purple }

**Risk Text**, **Cause Text**, **Consequence Text**, **Barrier Text** — font size and family for
each kind of card.

## The visual's own background and border

These come from Power BI's standard **General** section, so the bowtie follows your report theme.
